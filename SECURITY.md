# Security

For a suspected vulnerability, please use [GitHub private vulnerability reporting](https://github.com/senseFy/kmp-updater/security/advisories/new). Include the affected version, platform and a small reproduction where possible. Please omit real signing keys, tokens and personal app data.

For ordinary bugs and feature ideas, open an issue. Current platform support and acceptance coverage are in the [README](README.md) and [verification notes](docs/verification.md).
